# Zanskar 1.11.1

One cursor in desktop and application sessions, a Windows desktop that fills its pane at
any zoom or screen, and a notice that can be dismissed. Built with Go 1.27.3.

## Fixed

- **Two cursors over a desktop that did not line up.** In RDP, VNC and application
  sessions the remote pointer was drawn by the page as a second cursor that trailed the
  real one and did not line up with it, and stayed behind at the edge when the pointer
  left the desktop. Now, as Apache Guacamole's own client does it, the remote
  pointer is the browser's own cursor over the desktop, its shape and hotspot as the remote
  draws them, with no lag; outside the desktop, the usual cursor. Only for a pointer image
  the browser will not take (larger than 128 pixels) does the page draw it, and then in
  place of the browser's cursor, never beside it.
- **A Windows desktop filled two thirds of its pane** in a browser at a zoom or on a screen
  above 1x (seen in Brave). The page told guacd 96 DPI times the browser's pixel ratio, and
  guacd sizes an RDP session at the pane's width times 96 over that, on connecting and on
  every resize. The page now says 96 DPI whatever the screen, so the desktop is the pane's
  size at Windows' own 100% scale.
- **The desktop's right and bottom 6 pixels were cut off**, where a window's close button
  and scrollbars sit: the pane was padded but asked the remote for its size including the
  padding. The desktop now fills an unpadded pane.
- **A notice stayed until the page was left** (for example "Keycloak: 1 listed" after Sync
  now). Every notice in the console now has an x that dismisses it; a new result shows again.
- **The x that removes a tag, a group mapping or a time window was a few pixels wide.** It is
  an icon in a target large enough to hit.

## Upgrading from 1.11.0

Install the new package, or set `ZANSKAR_VERSION=1.11.1`, and restart. No migration
runs. The browser image's recipe is unchanged, so its layers are 1.11.0's.

A desktop session open during the upgrade keeps the size it connected with; the next one
fills the pane.
