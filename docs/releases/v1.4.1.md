# Zanskar 1.4.1

A security patch. Nothing in the gateway's own code changed: this is 1.4.0 rebuilt with Go
1.27.3 in place of 1.27.2, and nothing else.

Go 1.27.2 — the version 1.4.0 and the 1.5.0-rc.1 prerelease were built with — has a flaw in its
certificate checking (`crypto/x509`): under the right conditions it can keep trusting an
intermediate certificate that should be distrusted, which a man-in-the-middle can lean on. The
flaw is reachable from Zanskar: `govulncheck` reports the gateway's code reaches the affected
path (Go advisory GO-2026-6809, tracked as CVE-2026-111943, fixed in Go 1.27.3). Because Zanskar
verifies certificates when it talks to LDAPS directory servers, OIDC providers and upstream
targets, anyone running 1.4.0 or 1.5.0-rc.1 should move to 1.4.1.

There is nothing new to configure and no migration. Upgrade in place: replace the binary or pull
the new image and restart. Everything from the **Upgrading from 1.3.0** notes in the 1.4.0
release still applies if you are coming from further back.
