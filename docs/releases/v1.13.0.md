# Zanskar 1.13.0

What a walk through the live console found, fixed. A session's tab offers to connect again
when it ends, and the gateway pulls the images sessions need before the first one asks for
them. The recording player answers its keys straight away and fits the window, and a dozen
smaller things read and behave the same on every page. Built with Go 1.27.3.

## Added

- **Connect again.** A session runs in a tab of its own, and when it ends the dialog offers
  *Connect again* beside *Back to targets*: the same machine and protocol, in the same tab,
  without asking first. Where a credential is typed, it is asked for again.
- **The gateway pulls the images ahead.** Once an application is enrolled, the gateway pulls
  its browser image and the relay in the background, on start and every five minutes after,
  right after it removes earlier versions' images. A MySQL or MariaDB database gets its relay
  the same way. After an upgrade the new images arrive before the first user asks for them,
  instead of that user waiting minutes on the pull. A failing pull is a warning once in the
  log, and a development build pulls nothing.

## Changed

- **"Now" is a box under the wait.** Restart, Reboot, Stop, Install and *Apply and restart*
  ask how long live sessions may finish; under that field, *End live sessions and reboot now*
  (and so on) sets it to 0, and unticking gives back the minutes that were there. It replaces
  1.12.0's separate *Reboot now* button, which did not say what it was for. The main button
  still says *Reboot now* when the wait is 0, and a 0 typed in the field ticks the box.

## Fixed

- **The recording player answers its keys after Play.** Space, the arrows, Home, End and F
  work from anywhere on the page, for a terminal recording as for a desktop one. Before, Space
  scrolled the page and F did nothing until the player was clicked. A focused button keeps
  Space, so the keyboard still presses it.
- **A terminal recording fits the window.** It fits both ways now, with its controls in
  view; in a wide, short window they used to sit below the window's edge.
- **A desktop recording in a short window is drawn as large as the window allows**, instead
  of small with wide bars. Leaving full screen brings the player back where it was.
- **Why the gateway has no AWS identity, in a sentence.** The Autoscaling page showed the AWS
  SDK's error whole, in monospace. It says, for example, *This machine has no IAM role. Attach
  an instance profile to it.* The SDK's own text goes to the gateway's log.
- **No SSH host key on a host without SSH.** A Windows host reached over RDP no longer says
  *Host key: unknown*; the Hosts list shows a dash there.
- **A protocol reads the same on every page**: SSH, RDP, VNC, HTTP, WinRM, in Sessions, My
  sessions, Recordings, the player, Watch, failover, the event log and the Hosts list.
- **The policy editor marks a disabled user**, such as one its identity provider removed, and
  leaves it out of *Select all*.
- **Delete lives where a policy or a provider is opened**: the policy editor's footer and the
  provider's edit dialog, as a host's Delete is in its drawer, rather than a red button on
  every row. Credentials and groups, which have no editor, keep it in their row.
- **The empty Groups list** no longer says a policy needs a group: a policy can name users.
- **No read of the same thing twice as a page opens.** Every admin page read the gateway's
  status four times; it reads it once (the dashboard twice, the second to set its clock).
  The portal's Targets page read the user's grants twice.
- **The console's own files are logged at debug.** A page load wrote about ten info lines,
  one per script, style sheet and icon. The page itself, the API and any failure stay at
  info.
- **A second click on a session link is never lost.** Two quick clicks opened two tabs, and
  the second could ask *Connect?* instead of connecting.

## Upgrading from 1.12.0

Install the new package, or set `ZANSKAR_VERSION=1.13.0`, and restart. No migration runs, the
browser image is 1.12.0's recipe, and the API is unchanged: an AWS identity's `error` is now a
sentence, and the SDK's own text is in the log. On a host with an application enrolled, the
gateway removes 1.12.0's browser and relay images within a minute of starting and then pulls
1.13.0's (about a 270 MB download, 660 MB on disk) in the background; give the disk that room,
or pull them by hand first (see the deploy guide).
