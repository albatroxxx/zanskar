# Zanskar 1.11.2

A theme for everyone in Settings and a switch in the corner for one's own; a recording
player with icon controls and a full screen; an application that fills a full screen; and a
session dialog that reaches sign-in after the computer slept. Built with Go 1.27.3.

## Changed

- **A theme for everyone.** Settings has **Theme** under Display: system, light or dark.
  It applies from the sign-in page on, before the first paint, so no page flashes the other
  theme; a change applies at each person's next page load. System, the default, follows
  each device as before.
- **The corner's theme icon is a switch.** One click to the other theme, one click back, no
  menu; the circle's dark half swings over as the theme changes (not with reduced motion).
  The pick is this browser's own and is kept only while it differs from the theme for
  everyone: switching back to that follows everyone's again. Saving a theme in Settings
  shows it at once in the browser it was saved from.
- **The recording player's controls are icons**: play again, back and forward ten seconds,
  play and pause, each with its words in the tooltip and for screen readers.
- **A recording plays full screen**, the picture with the controls under it, from the
  button at the end of the controls or F. A desktop recording is drawn as large as the
  screen; a terminal recording fits the screen's height as well as its width.

## Fixed

- **An application in full screen stopped short of the bottom**, black below it. The
  isolated browser's window kept the size the session opened at; it now follows the screen
  as the pane changes, into full screen and back.
- **The session dialog stayed on "Taking you to sign in…"** after the computer slept, until
  a click outside it. It now waits five seconds for the gateway, then goes to the sign-in
  page.
- **A paused terminal recording went blank** under the player's start button when its speed
  changed. It now keeps the frame it stopped on, and Play goes on from there.

## Upgrading from 1.11.1

Install the new package, or set `ZANSKAR_VERSION=1.11.2`, and restart. No migration runs.

The browser image gains one small package (xdotool), so the first application session after
the upgrade downloads the new image. A browser that had picked Light or Dark in the old theme
menu keeps that pick; one on System follows the theme set in Settings.
